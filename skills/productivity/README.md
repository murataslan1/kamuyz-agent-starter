# Üretkenlik Skill'leri

Bu dizindeki skill'ler `shared-skills/` dizininden referans alınır. Aşağıdaki skill'ler KamuYZ programı ekip yönetimi için kullanılacaktır:

## Kullanılacak Skill'ler

| Kaynak | Skill | Amaç |
|---|---|---|
| `shared-skills/secretary/` | DAILY_BRIEF.md | Günlük öncelikli görev listesi |
| `shared-skills/secretary/` | PRIORITY_AUDIT.md | Gün ortası öncelik kontrolü |
| `shared-skills/secretary/` | WEEKLY_REVIEW.md | Haftalık sprint retrospektifi |
| `shared-skills/secretary/` | GOAL_ALIGNMENT.md | Görevlerin program hedefleriyle uyumu |

## Kullanım

Bu skill'ler `shared-skills/` dizinindeki orijinalleri üzerinden çalıştırılır. Bu dizin referans amaçlıdır — skill'leri doğrudan `shared-skills/` dizinindeki `.md` dosyalarından yükleyin.
