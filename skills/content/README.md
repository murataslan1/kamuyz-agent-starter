# İçerik Üretim Skill'leri

Bu dizindeki skill'ler `shared-skills/` dizininden referans alınır. Aşağıdaki skill'ler KamuYZ programı için kullanılacaktır:

## Kullanılacak Skill'ler

| Kaynak | Skill | Amaç |
|---|---|---|
| `shared-skills/youtube/` | RESEARCH.md | Etkinlik konuları için video fikir araştırması |

| `shared-skills/social-media/` | CLIPS.md | Etkinlik kayıtlarından kısa klip çıkarma |
| `shared-skills/social-media/` | SHORT_FORM.md | Reels/TikTok kısa içerik |

## Kullanım

Bu skill'ler `shared-skills/` dizinindeki orijinalleri üzerinden çalıştırılır. Bu dizin referans amaçlıdır — skill'leri doğrudan `shared-skills/` dizinindeki `.md` dosyalarından yükleyin.
