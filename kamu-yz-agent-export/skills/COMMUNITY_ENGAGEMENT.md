# COMMUNITY_ENGAGEMENT.md — Topluluk Katılımı Yönetimi

**Amaç:** Workshop sonrası katılımcılarla bağı sürdür, topluluğu canlı tut, sonraki etkinliklere katılımı artır.

**Hizmet Ettiği KPIs:** Kayıt sayısı, B2B dönüşüm

## Süreç

### Workshop sonu anında
```
- [ ] WhatsApp/Discord grubuna hoş geldin mesajı
- [ ] "Kendini tanıt" başlığı aç
- [ ] Kaynak linklerini sabitle (GitHub, KamuKOD, araştırma raporları)
```

### 1. hafta
```
- [ ] "Kurdunuz mu? Takıldığınız yer var mı?" sorusu
- [ ] 1 faydalı kaynak paylaş (güncel makale, video)
- [ ] Sonraki etkinlik duyurusu
```

### 2. hafta
```
- [ ] "Ne yaptırdınız ajana?" — kullanım örnekleri paylaşımı
- [ ] En aktif katılımcıya teşekkür / mention
```

### Sürekli
```
- [ ] Haftada 1 değerli içerik paylaş (haber, ipucu, kaynak)
- [ ] Ayda 1 etkinlik duyurusu
- [ ] Sorulara 24 saat içinde cevap ver
```

## Kalite Barı
- [ ] Hoş geldin mesajı workshop'tan sonra 24 saat içinde atıldı
- [ ] Haftada en az 1 değerli içerik paylaşıldı
- [ ] Sorulara 24 saat içinde cevap verildi
- [ ] Sonraki etkinlik duyurusu yapıldı
- [ ] Toksik/spam yok — gerektiğinde müdahale
