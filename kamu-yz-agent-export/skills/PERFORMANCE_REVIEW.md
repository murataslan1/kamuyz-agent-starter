# PERFORMANCE_REVIEW.md — Workshop Performans İncelemesi

**Amaç:** Workshop sonuçlarını analiz et, KPI'ları ölç, iyileştirme önerileri üret.

**Hizmet Ettiği KPIs:** Tümü

## Süreç (7 adım)

### 1. Veri toplama
```
Kaynaklar:
- NPS anket sonuçları (Google Forms / Typeform export)
- Katılım verisi (4 oturumdan kaçına katıldı?)
- Workshop kaydı (hangi dakikada izlenme düştü?)
- Chat log'u (kaç soru, hangi konular?)
- Demo başarı oranı (kaç katılımcı demo'yu tamamladı?)
```

### 2. KPI Scorecard
```
| KPI | Hedef | Gerçekleşen | Durum |
|---|---|---|---|
| NPS | >70   | [değer]     | 🟢/🟡/🔴 |
| Tamamlama | >85% | [değer]     | 🟢/🟡/🔴 |
| B2B dönüşüm | >15% | [değer]     | 🟢/🟡/🔴 |
| Kayıt (E1-E2-E3) | >100 | [değer]   | 🟢/🟡/🔴 |
| LinkedIn etkileşim | >5K  | [değer]     | 🟢/🟡/🔴 |
```

### 3. Modül analizi
```
Her modül için:
- Anlaşılma puanı (1-5)
- Soru sayısı
- Demo tamamlama oranı
- En sık takılan adım

→ En düşük 2 modülü iyileştirme listesine al
```

### 4. Öğrenci segmentasyonu
```
| Segment | Tanım | Ne yapmalı? |
|---|---|---|
| Hızlı | Tüm demoları tamamladı, ek soru sordu | KamuKOD 220'ye yönlendir |
| Standart | Ortalama katılım, ortalama başarı | KamuKOD 210'a yönlendir |
| Takılan | 2+ oturum kaçırdı, demo tamamlayamadı | Birebir destek teklif et |
| Sessiz | Katıldı ama hiç soru sormadı | Takip maili ile geri bildirim iste |
```

### 5. İçerik etkileşim analizi
```
LinkedIn/X gönderileri için:
- Gösterim sayısı
- Etkileşim oranı (like + yorum + repost / gösterim)
- En çok etkileşen gönderi tipi (görsel mi, alıntı mı, liste mi?)
- Tıklama oranı (link tıklaması / gösterim)

YouTube için:
- İzlenme süresi (ortalama)
- En çok izlenen bölüm (hangi dakika?)
- Terk etme noktası (hangi dakikada çıkıyorlar?)
```
