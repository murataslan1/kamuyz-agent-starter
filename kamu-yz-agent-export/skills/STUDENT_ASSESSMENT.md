# STUDENT_ASSESSMENT.md — Öğrenci Değerlendirme

**Amaç:** Workshop katılımcılarının ilerlemesini değerlendir, takılanları belirle, ek destek sağla.

**Hizmet Ettiği KPIs:** NPS, tamamlama oranı

## Süreç

### Oturum içi değerlendirme
```
Her oturum sonunda (son 5 dk):
- [ ] 1-5 yıldız hızlı anket: "Bu oturum ne kadar anlaşılırdı?"
- [ ] 1 açık uçlu soru: "En çok nerede takıldın?"
- [ ] Chat'teki soru sayısı ve türü (teknik / kavramsal / lojistik)
```

### Oturum arası takip
```
İkinci oturum başında:
- [ ] Önceki oturumun mini quiz'i (3 soru, 2 dk)
- [ ] En çok takılan konuyu 5 dk tekrar et
```

### Workshop sonu değerlendirme
```
NPS Anketi (Google Forms veya benzeri):
1. Bu workshop'u bir arkadaşına tavsiye eder misin? (0-10)
2. En değerli bulduğun şey neydi?
3. En az değerli / geliştirilmesi gereken şey neydi?
4. Workshop sonrası ne yapmayı planlıyorsun?
5. (Opsiyonel) İsmin ve iletişim bilgin (B2B takibi için)
```

### Değerlendirme karar ağacı
```
IF NPS > 70 VE tamamlama > 85%
  → Müfredata dokunma, lojistiği tekrarla

ELIF NPS 50-70 VEYA tamamlama 70-85%
  → Hangi modülde düşüş var? → O modülü iyileştir (CURRICULUM_DESIGN)

ELIF NPS < 50 VEYA tamamlama < 70%
  → Kök neden analizi yap:
    - Teknik sorun mu? (demo çalışmadı, ortam hatası)
    - İçerik sorunu mu? (çok hızlı, çok teknik, sıkıcı)
    - Lojistik sorun mu? (saat, süre, platform)
  → HANDOFF: MURAT (insan kararı)
```

## Kalite Barı
- [ ] Her oturumda değerlendirme yapıldı
- [ ] NPS anketi gönderildi (workshop sonu)
- [ ] Düşük puanlı alanlar işaretlendi
- [ ] İyileştirme aksiyonları CURRICULUM_DESIGN'a iletildi
- [ ] B2B potansiyeli olan katılımcılar işaretlendi → B2B_PROPOSAL
