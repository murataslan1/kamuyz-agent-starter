# HEARTBEAT.md — Workshop Ajanı Çalışma Ritmi

## Günlük Döngü (~15 dk)

```
HER SABAH:
1. Bağlamı oku → journal/, MEMORY.md
2. Takvimi kontrol et → yaklaşan workshop var mı?
3. Karar ağacına göre 1-2 skill çalıştır
4. journal/'a kaydet
```

## Karar Ağacı

```
IF workshop 7 gün içinde başlıyorsa
  → WORKSHOP_LOGISTICS (davet, materyal, ortam hazırla)

ELIF workshop 3 gün içinde başlıyorsa
  → LIVE_DEMO_SCRIPT (demo'yu prova et, kuru çalış yap)

ELIF workshop DEVAM EDİYORSA
  → STUDENT_ASSESSMENT (ara değerlendirme)
  → CONTENT_REPURPOSE (oturumdan klip/blog çıkar)

ELIF workshop BİTTİYSE (son 48 saat)
  → PERFORMANCE_REVIEW (NPS, katılım, içgörüler)
  → COMMUNITY_ENGAGEMENT (teşekkür, sonraki adım)
  → B2B_PROPOSAL (kurumsal ilgi varsa teklif hazırla)

ELIF yeni araştırma/versiyon yayınlandıysa
  → CURRICULUM_DESIGN (müfredatı güncelle)

ELIF içerik takvimi boşsa
  → CONTENT_REPURPOSE (araştırmadan blog/LinkedIn üret)

ELSE
  → CURRICULUM_DESIGN (müfredatı iyileştir, yeni modül ekle)
```

## Haftalık Döngü (Pazartesi)

```
1. Workshop pipeline'ını değerlendir
2. B2B lead'leri tara → takip edilmesi gereken var mı?
3. LinkedIn/X performansını incele
4. Müfredat güncelleme ihtiyacı var mı?
5. MEMORY.md'yi güncelle (ne öğrendik?)
6. Gelecek haftanın içerik takvimini oluştur
```

## Workshop Öncesi (T-7 gün)

```
- [ ] Katılımcı listesini kontrol et
- [ ] Hoş geldin mailini gönder
- [ ] Teknik gereksinimleri hatırlat (Node.js, Docker, Telegram)
- [ ] Zoom linkini oluştur
- [ ] Demo ortamını test et (kuru çalış)
```

## Workshop Sırası (canlı)

```
- [ ] Oturum başında gündemi paylaş
- [ ] Her bölüm sonunda "sorusu olan?" diye sor
- [ ] Demo'yu canlı yap, ekran görüntüsü al (sonradan klip için)
- [ ] Chat'i takip et — takılanları not al
- [ ] Oturum sonunda mini anket (1-5 yıldız)
```

## Workshop Sonrası (T+48 saat)

```
- [ ] Kaydı düzenle, YouTube'a yükle
- [ ] Katılımcılara teşekkür maili + kayıt linki gönder
- [ ] NPS anketini gönder
- [ ] 2-3 kısa klip çıkar (LinkedIn/Reels için)
- [ ] Öğrenilenleri journal/'a kaydet
```
